02 / The details matter

不只是换一个扩展名。More than a new extension.

01 — NOTATION

让六线谱保持完整Keep the tablature

Guitar Pro 转 MusicXML 保留 TAB、调弦与每个音的弦号品位。MusicXML、PDF、PNG 可选择六线谱或五线谱。纯五线谱保留音高，转回 TAB 时重新分配弦品。Guitar Pro to MusicXML retains TAB staves, tuning and each note's string/fret data. Choose tablature or standard notation for MusicXML, PDF and PNG. Standard notation preserves pitch; converting back to TAB reassigns string/fret positions.

02 — ARRANGEMENT

04 / Good to know

使用前，了解这些。A few things to know.

文件会上传到云端吗？Are my files sent to the cloud?

桌面版在本机转换。Web 版会把文件传给你使用的部署服务器，本机运行服务器时文件不会离开本机。本官网只提供介绍、下载和文档入口，不接收乐谱上传。Desktop conversion runs on your machine. The web app sends files to the server you use; a local server keeps them local. This website provides information, downloads and documentation, with no score uploads.

首次启动被系统拦截怎么办？What if the OS blocks the first launch?

应用未做正式开发者签名与公证。macOS 可到「系统设置 → 隐私与安全性」选择「仍要打开」；Windows 在 SmartScreen 中选择「更多信息 → 仍要运行」。The app has no formal developer signing or notarization. On macOS, select “Open Anyway” in System Settings → Privacy & Security. On Windows, select “More info → Run anyway” in SmartScreen.

GP5 导出有哪些取舍？What are the GP5 export limits?

自研写出器保留音符、节奏与 GP5 支持的演奏效果，并经 alphaTab 与 MuseScore 双解析器回读校验。不保留和弦图，非 ASCII 文本会变为问号。非吉他谱转 GP5 时，超出音域的音符可能按八度折叠；歌曲 JSON 路径会在音高改变时报错。The custom writer preserves notes, rhythms and supported techniques, with readback checks through alphaTab and MuseScore. Chord diagrams are omitted and non-ASCII text becomes question marks. Non-guitar scores may have out-of-range notes folded by octaves; song JSON conversion fails if pitches would change.

转换后的谱子需要校正吗？Will I need to correct the converted score?

MIDI 缺少声部、连音线等谱面信息，记谱由 MuseScore 量化推断，通常需要整理。识别草稿也需对照原谱。歌曲 JSON 的跨软件连音播放存在已知差异，Guitar Pro 桌面端尚未人工试听确认，详见 README。MIDI lacks engraving details such as voices and ties; MuseScore infers notation through quantization, so manual cleanup is often needed. Check recognized drafts against the original. Song JSON has known tie-playback differences between apps and has not been manually auditioned in Guitar Pro; see the README.

为什么 PNG 长图导出失败？Why did my long PNG export fail?

长图有 1 亿像素上限，超过时会报错。降低 DPI 后重试，或选择普通 PNG，将多页图片打包为 ZIP。每个输入文件最大 50 MB。Long PNG exports are limited to 100 million pixels. Lower the DPI or choose regular PNG for a ZIP of separate pages. Each input file is limited to 50 MB.
